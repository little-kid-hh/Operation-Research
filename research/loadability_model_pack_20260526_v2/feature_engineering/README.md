# Feature Engineering

The feature-engineered SVM uses the cumulative active bank from the formal
no-seed GLM run.

## Contents

- `build_active_bank.py`: rebuild the active bank from the accepted trial
  feature scripts.
- `accepted_trials/`: the accepted feature generators in iteration order.
- `reference_active_bank.csv`: the reference bank used to train the saved
  feature-engineered SVM.
